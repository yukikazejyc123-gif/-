# 小小账本 · Little Ledger

简约可爱的安卓现金记账应用，搭配奶油白、鼠尾草绿和会眨眼的考拉。支持中文、日文、韩文、英语，适合手动记录日常开销和旅行账目。当前测试版 **0.5.0**。

![账本管理](docs/images/books.png)

## 安装与使用

- [下载 Android 0.5.0 安装包](../downloads/little-ledger-0.5.0.apk?raw=true)

最低 Android 8.0。已有旧测试版时可以直接覆盖安装，原账目自动进入“默认账本”。首次安装为空账本，源码中的预览演示数据不会写入手机账本。

## 功能

- 新增、改名和切换多个账本，例如日常开销、9月旅行、人情往来；每本单独保存分类、账目、每月预算和主货币，最多 50 本。
- 本月收支、结余、账单明细、分类统计和每日趋势；年度总额与 12 个月收支汇总。
- 首页直接点击日期看明细，任意过去或未来日期都可记录，“今天”返回日本当前日期；未来账目立即计入对应月份。
- 月度分类预算、接近限额与超支提示，可沿用上月预算。
- 手动现金记录、金额加减键盘、连续记账、编辑、搜索和删除明细。
- 8 种货币：JPY、CNY、USD、EUR、GBP、HKD、TWD、KRW。每笔保存原币金额、固定汇率、报价日期及主币换算结果。
- 每本可更改主货币；账目和预算一起换算，保留原金额与历史换算记录。切回旧主币可以复用历史结果。
- 统一风格的币种与预算分类选择面板，25 种分类插画与 5 种背景色；分类可自定义四种语言的名称。
- 四语言界面、内置日文字体 Zen Maru Gothic 和韩文字体 Noto Sans KR，可离线使用。用户填写的账本名称和备注保持原样。
- 考拉的眨眼、弹跳、歪头、挥手及「＋1」只是互动，不改变收入或账目；面板与日期采用约 150 毫秒的短动画。
- 完整 JSON 备份涵盖全部账本，恢复前预览并确认，保留恢复前副本，可撤销；兼容旧单账本备份。
- CSV 导出当前账本全部明细，含原币与主币换算信息，支持 BOM、Unicode、逗号、引号和换行。

## 数据与网络

账本存放在应用内部目录，应用不上传账单。联网仅由原生客户端向 [Frankfurter](https://frankfurter.dev/) 获取货币对的参考报价，不发送金额、分类、备注或账目日期。报价单独缓存，断网可使用最近汇率，也允许手动修改。保存后的账目不会随新报价重算。自动报价不是历史成交价或未来汇率预测。

数据格式 5 在集合中保存多个独立的格式 4 账本；版本 1–4 自动迁入默认账本，保留日期、ID、金额、备注、分类、预算和换算记录。写入前保存旧文件副本，并使用 AtomicFile 原子保存；读取失败时阻止覆盖。应用关闭系统自动备份，文件导入导出使用 Android 文件选择器，换手机时应先保存完整 JSON 备份。

## 实现与构建

采用 **Java 17 + Android WebView**，页面、逻辑、字体和插画全部打包到 APK 内。当前没有改写成 Kotlin/Compose。

- `ledger-core.js`：整数最小货币单位、精确十进制换算、预算、多账本迁移与备份。
- `ledger-ui.js` / `ledger-en.js` / `ledger.css`：四语言界面和交互。
- `LedgerValidator.java`：原生保存边界的数据检查，用 BigDecimal 与 JS 保持相同舍入规则。
- `ExchangeRateClient.java`：原生汇率请求和缓存，检查币种、日期、精度、响应大小与超时。

需要 JDK 17、Android SDK Platform 35 和 Build Tools 35.0.0。Gradle Wrapper 8.13、Android Gradle Plugin 8.13.2。用 Android Studio 打开本目录并配置 SDK，或在本目录运行：

```powershell
.\gradlew.bat assembleDebug lintDebug testDebugUnitTest
```

`local.properties`、构建缓存和签名私钥不提交。没有本地开发私钥时采用 Android 默认 debug 签名，可以正常编译。作者提供的安装包保留原测试签名；自行构建的包使用另一签名，不能直接覆盖作者测试包。`dev-signing/test.keystore` 仅在作者本地保留。
