# 小小账本 0.5.2 使用说明

这版采用选定的A首页方案，增加月历入口和每天支出，金额与数字键盘相邻，分类预算可以查看对应账目。四语言、多账本、换币、考拉互动与已有界面细节修复继续保留。

## 安装与原账目

用「小小账本-0.5.2-安卓测试版.apk」覆盖安装旧版，不要先卸载。可以先在「我的 → 保存完整备份」保存一份 JSON。

首次安装得到空的默认账本。从 0.5.0 或 0.5.1 覆盖升级时保留全部已有账本和数据。从 0.4.x 或更早版本升级时，原有账目、分类、每月预算、原币金额和换算记录归入“默认账本”；首次写入新格式前，应用保存原文件副本。

## 新增和切换账本

点击首页考拉标题下方的账本栏，或打开「我的 → 管理账本」。点击「新增账本」，填写“日常开销”“9月旅行”“人情往来”等名称，保存后进入新账本。列表右边的铅笔可以改名，点击账本卡片切换。

每个账本单独保存账目、分类、各月份预算和主货币，月度及年度统计只计算当前账本。新账本继承当前账本的币种和分类样式，账目、预算和已存汇率为空；以后修改分类或主币不会影响其他账本。最多可建 50 本，名称最多 40 个字符。

语言和轻快动画是整个应用的设置，切换账本后保持一致。当前版提供新增、改名和切换，没有加入删除账本。

## 英语和选择面板

「我的 → 界面语言」可选择中文、日本語、한국어、English。英文界面包含日期、货币名、默认分类、提示、预算和 CSV 表头。用户自己填写的备注、账本名称与分类名称不会自动翻译；自定义分类可填写英文名称，留空时使用主名称。

记账页面点击金额旁边的币种，打开同风格面板；点选后返回记账页面，已经输入的金额和备注保留。预算的分类选择也使用相同面板。可点击空白遮罩、关闭按钮或系统返回关闭。面板过渡约 150 毫秒，可在「轻快动画」关闭，也尊重系统减少动画设置。

## 日期、考拉和多货币

首页继续直接点击日期切换当天明细；“今天”返回日本当前日期。过去与未来都可记账，未来账目立即计入该月份统计和预算。考拉的眨眼、弹跳、歪头、挥手和「＋1」仅是互动，不创建收入或改变账目。

支持 JPY、CNY、USD、EUR、GBP、HKD、TWD、KRW。每筆可选原币，以当前账本主币统计；「我的 → 主货币」会显示换算预览，确认后该账本已有账目与预算一起换算，其他账本不变。原币金额与各主币历史换算记录保留；切回旧主币可以复用。

联网获取参考汇率，断网时使用最近缓存，也可手动填写实际汇率。自动报价不是过去某天的成交价或未来汇率预测。保存后的金额不会随新报价变化。日元和韩元使用整数，其他支持货币使用两位小数。

## 备份和导出

「保存完整备份」包含所有账本、预算、分类、币种、换算记录和应用设置。恢复前会预览账本数与总记录数，确认后替换全部账本；恢复前保存全部账本副本，可以撤销上次恢复。旧版单账本备份仍可恢复为默认账本。

「导出当前账本 CSV」只导出正在使用的账本明细，包含原币和主币换算信息；CSV 不代替完整 JSON 备份。

账目保存在手机中，联网仅获取货币对报价，不发送账单金额、分类、备注或日期。当前实现为 Java + Android WebView。电脑端检查不等于 X300 Pro 实机测试，手机上的实际安装、关闭重开、文件选择和手势体验仍需试用。

## 0.5.2 新增操作

- 记一笔：金额框紧接数字键盘，先输入金额，再向下选择分类、日期和备注，最后保存；加减计算与连续记账仍可用。
- 每日花费：在首页点「月历」打开整月日历。每格下方是当天支出，无支出显示「—」。切换月份、点具体日期看明细，或点「今天」返回日本当前日期。未来记录立即计入所属日期和月份。长金额为适应日期格会简写，进入当天明细可看完整金额。
- 预算明细：在首页或「分类预算」点分类卡片，例如交通额度¥5,000、已有¥1,000和¥1,300两笔支出，会显示已花¥2,300、剩余¥2,700和两条明细。点记录查看或编辑、删除；点「编辑预算」修改额度。上方可切月份，同一分类的各月独立计算。
- 所有上述花费按当前账本主币统计，外币使用每笔已经保存的换算金额，不用新汇率重算历史；收入不计入支出或预算。
