# 小小账本 0.5.1 验证结果

2026-10-01 根据试用反馈修复界面细节，数据格式仍为 5。本轮没有修改财务计算、账本迁移或原生数据校验规则。

## 已完成的修复

- 移除设置页口号卡、账本管理说明卡与重复副标题、空页面鼓励段落；保留必要的备份、汇率和数据范围说明。
- 分类管理仅显示当前语言名称，隐藏分类显示本语言状态；各语言名称仍保留在原数据中。分类编辑预览按当前语言选择名称，随输入更新且保持输入焦点；取消编辑不保存草稿。
- 25 个分类插画按各自真实边界裁切与居中，保留比例，避免书本图标带入相邻图案残片。不同使用位置仍使用同一图标库。
- WebView 设置 `OVER_SCROLL_NEVER`，页面与选择列表禁用 CSS overscroll。普通竖向滚动、日期短动画、面板动画与考拉互动保留。
- 项目新增 `AGENTS.md`、`docs/PROJECT_CONTEXT.md` 和可随源码运行的浏览器反馈回归测试。
