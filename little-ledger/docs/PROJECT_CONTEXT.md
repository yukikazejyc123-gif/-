## 已确认的产品方向

面向个人现金手动记账，以日本使用为初始场景，默认日元。数据放在手机本地，日常记账、查询与统计离线可用。

- 首页展示本月收入、支出、结余和账单明细；支持分类统计、每日趋势、搜索与明细编辑。
- 年度页面展示当年总收支与 12 个月汇总，点月份查看明细；月份可单独切换。
- 日期可以自由选到过去或未来。未来记录立即作为所属月份的普通账目计入统计和预算，不另设“计划账目”口径。
- 预算按每月 1 日到月底计算，给常用分类单独设限，各月份独立保存。
- 支持中文、日文、韩文、英语。用户自己填写的账本名称、分类名称与备注不自动翻译；分类可另填四语言名称。
- 同一本账本记录多币种，并按可修改的主币统一统计。支持 JPY、CNY、USD、EUR、GBP、HKD、TWD、KRW。
- 汇率联网自动获取，断网使用最近缓存，也允许手动修改。报价是参考汇率，不等于某笔现金兑换的成交价。
- 支持新增、改名、切换多个账本。每本的账目、分类、月预算和主币独立；当前版本不提供删除账本。

## 设计思路及已落地成果

界面保持简约可爱，奶油白作为纸面，鼠尾草绿作为主色。可爱由考拉与统一的柔软立体插画提供；完成度依靠一致的圆角、留白、金额层次、卡片边缘和柔和光影。当前有 25 种分类插画与 5 种背景色，自定义分类从同一图标库选择。

标题旁的小考拉头像与首页大考拉均保留。大考拉有睁眼、闭眼与挥手姿态，点击给轻快反馈并飘出「＋1」。**互动只改变视觉，不生成收入或账目。** 日期切换保留原有直接点击方式，仅增加约 150 毫秒的过渡；币种和预算分类使用同风格应用内选择面板。

日文内置 Zen Maru Gothic，韩文内置 Noto Sans KR，手机离线也能显示；中文与英语采用清楚的系统无衬线字体。分类图标、导航图标、字体及插画使用同一套本地资源，新增资源需同步原生白名单与打包检查。

## 技术架构与入口

当前为 **Java 17 + Android WebView**，不是 Kotlin/Compose。页面、脚本、样式、字体和图片全部打包到 APK。原生 WebView 从应用内 HTTPS 主机读取白名单资源，页面没有外部网络连接能力；汇率由原生客户端独立获取。

| `app/src/main/assets/bootstrap.js` | 读取原生账本，提供存储、导出、恢复和汇率适配接口 |
| `app/src/main/assets/ledger-core.js` | 数据规范化、精确金额、预算、账本集合、迁移、换币、备份与 CSV |
| `app/src/main/assets/ledger-ui.js` | 页面、交互、中文/日文/韩文文案与状态管理 |

## 数据与安全合同

当前根数据是格式 5 的账本集合：

```text
{ version: 5, activeBookId, books: [{ id, name, data: 格式4账本 }], preferences }
```

`preferences` 保存语言、配色、圆角、考拉显示和动画开关。每本格式 4 数据保存 `currency`、`transactions`、`categories`、`budgets`、`budgetValuations`、`exchangeRates`、`design` 与 `nextId`。全局偏好与逐本业务数据的边界不能混用。最多 50 本，总记录上限按整个集合校验。

旧格式 1–4 自动进入 ID 为 `default` 的默认账本，旧 ID、日期、金额、分类、备注、预算和汇率含义保留。首次读取不必写回；真实保存时完成格式升级。新账本继承当前币种和分类样式，记录、预算及已有汇率为空，之后互不影响。

金额用最小货币单位整数保存。JS 使用 BigInt，原生使用 BigDecimal，结果按主币最小单位四舍五入。每笔保留原币 `amount`/`currency`，当前主币的 `rate`/`convertedAmount`/可选 `rateDate`，以及各主币的 `valuations` 快照。

改主币通过完整预览后一次性保存目标模型。新目标从每笔原币直接计算；旧目标优先复用已有快照。预算同步换算，在 `budgetValuations` 保留额度、来源币种、来源金额和汇率。金额溢出阻止保存；极小外币账目可以换算为零，正预算换算为零则阻止换币。改原币金额、币种或汇率使旧快照失效；只改备注、分类或日期保留快照。

原文件名仍为 `ledger-v1.json`，不代表其内容仍是格式 1。原生使用 AtomicFile，迁移、换币及恢复前保留对应字节副本；读取异常时不能用空模型覆盖原始文件。保存失败要回滚界面内完整集合。更换账本或离开编辑页后，迟到的汇率响应不能影响新账本或覆盖手动汇率。

完整备份格式为 `koala-ledger-backup`、`backupVersion: 2`，包含全部账本和全局设置；旧 `backupVersion: 1` 的单账本备份仍兼容。恢复先预览，再明确确认替换**全部账本**，保存恢复前快照，撤销恢复整个集合。CSV 只导出当前账本明细，不能恢复预算、分类或全集合。

联网只请求支持的货币对，不发送业务账目；保留最近报价缓存及手动入口。账目保存后的汇率是固定快照，新报价不重算历史。源码、下载包与项目文档不包含签名私钥、认证信息、真实账本、本机 SDK 路径或构建缓存。
