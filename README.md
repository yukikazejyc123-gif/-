## 小小账本 · Little Ledger

平时在日本生活，基本都是现金支付，所以只做了基础的现金记账功能，目前支持中文、日文、韩文和英语，提供多个独立账本、月度分类预算、多货币、年度账单和本地备份。未来可能会加入ocr识别功能
